# Event Sequencer

A stripped-down, reimagined take on [TidalCycles](https://tidalcycles.org/) for Mac OS 9: a text language for expressing rhythmic and compositional patterns, driving the built-in audio engine.

## Build

CodeWarrior for Mac OS 9 — create a new project and add `src/event-sequencer.c` as the only source file.

## Source

`src/event-sequencer.c`
