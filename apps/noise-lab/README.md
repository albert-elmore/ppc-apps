# Noise Lab

Percussion-oriented waveform designer: noise and sine layers, envelopes, looping, sample-and-hold, filtering, and export workflow for drum-like samples.

## Build

CodeWarrior for Mac OS 9 — create a new project and add `src/noise-lab.c` as the only source file.

## Source

`src/noise-lab.c` — 44.1 kHz, Sound Manager double-buffering.

## Releases

Tag releases as `noise-lab/v1.3`, `noise-lab/v1.4`, etc. (initial import corresponded to the former `noise-lab-1.3.c`).
