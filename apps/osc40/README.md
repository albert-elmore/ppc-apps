# Osc40

Forty-oscillator composition tool. Notes drift randomly over time; sliders control change rate, pitch range, gain, notes per event, fades, per-oscillator mute, and paging across all voices.

## Build

CodeWarrior for Mac OS 9 — create a new project and add `src/osc40.c` as the only source file.

## Source

`src/osc40.c` — 11.025 kHz, 40 oscillators, Sound Manager double-buffering.

## Releases

Tag releases as `osc40/v1.0`, `osc40/v1.1`, etc. (initial import corresponded to the former `osc40-1.0.c`).
